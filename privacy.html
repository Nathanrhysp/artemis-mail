Artemis Mail privacy policy

Last updated 26 November 2026.

Artemis Mail is a personal tool used only by its owner with the owner's own Google accounts. It is not available to anyone else.

What it accesses

With the owner's consent, it uses the Gmail API scope https://www.googleapis.com/auth/gmail.readonly to search and read the owner's email messages and labels. It does not send, modify, label or delete mail, and does not download attachments.

How data is used and stored

  • Email is retrieved only when the owner's assistant needs it to answer the owner's own request.
  • Processing happens on the owner's own self-hosted computers. Google access tokens are stored on those machines with owner-only file permissions.
  • Service logs record only operation names, counts and timings, never message content.
  • No data is sold, shared with third parties, or used for advertising or to train models for others.

Google API Services User Data Policy

Artemis Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
