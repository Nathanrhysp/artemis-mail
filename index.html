Artemis Mail

Artemis Mail is a private, single-owner assistant tool. It lets the owner's self-hosted home assistant read the owner's own Gmail so it can find receipts, bookings and threads on request.

It is not offered to the public, has no sign-up, and is used only with the owner's own Google accounts.

  • Access is read-only (gmail.readonly). It cannot send, change or delete mail.
  • Mail is processed on the owner's own computers and is never sold, shared or used for advertising.
